heightfield bakers

fillField2 bakes FBM into a caller Float32Array in one zero-alloc pass. ridged2 / billow2 reshape the octaves.

Bake cost is shown in microseconds for a live 256x256 field. ridged2 gives sharp creases (mountains); billow2 gives folded puffs (clouds).

two independent fields

the isolation fix

Each createNoise() owns its 512-byte table. Two systems on one page never collide -- the NS-01 fix.

reseed A -- watch B

Instance mode: reseed A, B is untouched. Shared mode: both panels read the one module table, so reseeding "A" (a seedNoise call) visibly corrupts B. That collision is the bug createNoise exists to kill.
